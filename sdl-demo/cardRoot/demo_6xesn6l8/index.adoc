== Welcome to the Cyberismo Demo Project!

This demo showcases the Cyberismo solution in action.


=== Secure development

Here’s what you can explore:

*Get Familiar with Secure Development.* Dive into the structure of an IoT device development project and see how everything fits together. Check out {{#xref}}"cardKey":"demo_xqe6azge"{{/xref}}.

*Test Automatic Progress Metrics.* Mark a development task as not required using the *Mark as out of scope* workflow transition, and watch the progress metric update instantly. Notice how the tool will require you to enter a justification before this transition can be executed. 

*Explore How Tasks Interconnect.* Open {{#xref}}"cardKey":"demo_i5kwzzjx"{{/xref}} and click *View diagram* to visualize how tasks interconnect.

*Use the Awesome Modeling Tools.* Check out the {{#xref}}"cardKey":"demo_mrjvy0w6"{{/xref}} and tweak the threat model — the diagrams update automatically based on component and data flow changes!

*Trace Risks to Weaknesses & Requirements.* See how xref:demo_mjibofs4.adoc[an example risk] links to xref:demo_af76k982.adoc[a weakness] and a xref:demo_i8gd0sav.adoc[security requirement].

*Monitor Project Progress.* Visit {{#xref}}"cardKey":"demo_n78crkpq"{{/xref}} for an overview of the project's status.

*Create a New Project.* Click *Create* (top right) and start a new development project. Select "Create on top level" at the bottom of the diaglo. Tip: Search for Start to quickly find the template.

Jump in and explore. Cyberismo makes security-driven development seamless!
