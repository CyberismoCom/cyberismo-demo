== Welcome to the Cyberismo Demo Project!

This demo showcases the Cyberismo solution in action.


=== Secure development

Here’s what you can explore:

*Get Familiar with Secure Development.* Dive into the structure of an IoT device development project and see how everything fits together. Check out {{#xref}}"cardKey":"demo_yql655ra"{{/xref}}.

*Test Automatic Progress Metrics.* Mark a development task as not required using the *Mark as out of scope* workflow transition, and watch the progress metric update instantly. Notice how the tool will require you to enter a justification before this transition can be executed. 

*Explore How Tasks Interconnect.* Open  {{#xref}}"cardKey":"demo_4umgchca"{{/xref}} and click *View diagram* to visualize how tasks interconnect.

*Use the Awesome Modeling Tools.* Check out the {{#xref}}"cardKey":"demo_c9v5ihw7"{{/xref}} and tweak the data flow model — the diagrams update automatically based on component and data flow changes!

*Trace Risks to Weaknesses & Requirements.* See how xref:demo_2lqrrvhv.adoc[an example risk] links to xref:demo_sximbgjl.adoc[a weakness] and a xref:demo_qzukeub2.adoc[security requirement].

*Monitor Project Progress.* Visit {{#xref}}"cardKey":"demo_dingfe8d"{{/xref}} for an overview of the project's status.

*Create a New Project.* Click *Create* (top right) and start a new development project. Select "Create on top level" at the bottom of the diaglo. Tip: Search for Start to quickly find the template.

Jump in and explore. Cyberismo makes security-driven development seamless!
