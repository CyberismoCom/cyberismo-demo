== Introduction

This document is a technology assessment for the purpose of storing the IoT device configuration locally on the device.

The assessed technology is SQLite 3.46.x, embedded as a library in the device firmware. It backs the *Configuration data* data store in the threat model: the administration web application writes device configuration to it, and the runtime data handler reads that configuration at start-up and on change.

The assessment covers SQLite as an embedded local store only. It does not cover use of SQLite for the buffered telemetry queue, which is a separate decision and is currently a flat file.

== Conclusion

SQLite is adopted for the device configuration store. All checklist items are OK and no escalation was required.

Two conditions apply to the adoption, both of which are already reflected elsewhere in this project:

* Confidentiality of stored secrets is handled at the application layer, not by the store. SQLite provides no encryption at rest in the configuration we use.
* The component stays on the third party vulnerability monitoring list, and a SQLite security fix is grounds for a firmware release even outside the normal cadence.
